# Tabela de Vantagens

> **Nota.**
> **Custo e efeito em números, do GURPS Módulo Básico.** Sem descrição literária: o que está aqui é o que muda rolagem. **Quando a vantagem dá bônus em perícia, as perícias estão nomeadas** — é isso que a coluna *Bônus* da ficha (`24`) precisa para ser auditável.
> **Vantagem fora desta lista pode ser comprada pelo livro.** Se o custo divergir, **vale o livro**, e o Árbitro corrige por linha nova.
> **Versão 3, de 10/09/2026.** Corrigidos: Abascanto (dobra contra área), Empatia com Animais (a lista de perícias é aberta), Força de Vontade (resiste a qualquer mágica resistível, e também a Diplomacia, Lábia e Sex-Appeal), Longevidade (bloqueia os pontos de Idade), Talento para Matemática (a exceção e o +2 de Engenharia), Talento Musical (é bônus de aprendizado) e a manutenção de Status, que é **mensal**, não semanal.

## Aliado

| Poder do Aliado | Custo |
| --- | --- |
| menos de 75 pontos | **é Dependente**, e é desvantagem |
| 76 a 100 pontos | 5 |
| 101 a 150 pontos | 10 |
| 151 a 200 pontos | 15 |
| 50 pontos acima de você | **é Patrono** |
| habilidades especiais (magia onde não há magia, equipamento acima do NT) | +5 a +10 |

| Frequência | Jogada | Multiplicador |
| --- | --- | --- |
| quase todo o tempo | ≤15 | ×3 |
| com bastante frequência | ≤12 | ×2 |
| frequentemente | ≤9 | ×1 |
| esporadicamente | ≤6 | metade, arredondando para cima |

**Autômato é Aliado** (`25`, decisão 10): fabricado só por Encantamentos, aparece **quase todo o tempo (×3)**, **não pensa**, e **para em bolsão de mana nula**.

## Patrono

| Poder | Custo |
| --- | --- |
| indivíduo de 150+ pontos, ou grupo com bens 1.000× os recursos iniciais | 10 |
| indivíduo de 200+ pontos, ou organização razoavelmente poderosa | 15 |
| organização muito poderosa | 25 |
| governo nacional ou organização gigantesca | 30 |

Modificadores: **+5** se fornece equipamento útil; **+10** se o equipamento vale mais que os recursos iniciais da campanha; **+5 ou +10** por qualidades especiais. Frequência: a mesma tabela do Aliado. **Contato uma vez por aventura**, e o custo **não** se divide entre quem compartilha o mesmo Patrono.

## Reputação

**Três fatores que se multiplicam.** Arredonde para baixo em cada corte.

| Tipo | Valor |
| --- | --- |
| +1 a +4 de reação | **5 pontos por ponto**, máximo +4 |
| −1 a −4 de reação | −5 por ponto, máximo −4 |

| Quem te conhece | Fator |
| --- | --- |
| todos que você encontrar | valor cheio |
| **grupo grande** — uma cidade inteira, todos os mercenários, todos os mercadores | **metade** |
| **grupo pequeno** — os sacerdotes de uma Casa, quem leu seus escritos | **um terço** |
| classe pequena demais para aparecer em jogo | **não vale nada** |

| Com que frequência te reconhecem | Jogada | Fator |
| --- | --- | --- |
| o tempo todo | — | sem modificador |
| de vez em quando | ≤10 | metade |
| ocasionalmente | ≤7 | um terço |

## Status

**5 pontos por nível**, de −4 (escória) a 8 (considerado divino).

| Item | Valor |
| --- | --- |
| Modificador de reação | **a diferença entre o seu Status e o do NPC** |
| Status negativo | a mesma diferença como redutor, com piso de −4 |
| Trato Social pré-definido, com Status alto | IQ+2 na própria cultura, IQ nas demais |
| Desconto | Riqueza **Rico** ou acima paga 5 a menos por Status elevado |
| Manutenção | **custa dinheiro todo mês** — é o Custo de Vida Mensal do MB pág. 191, subtraído da renda. **Não é semanal**; a versão 1 desta tabela dizia semanal e cobrava quatro vezes o devido |

# 3. As Dádivas — vantagem que só a Casa concede

**Dádiva é vantagem sobrenatural comprada com pontos normais, mas só dentro do domínio da sua divindade.** Fora do domínio, não existe compra possível.

| Casa | Concede |
| --- | --- |
| Atena | Reflexos em Combate · Bom Senso |
| Thoth | Memória Eidética · Facilidade para Línguas |
| Tyr | Hipoalgia |
| Ixchel | Intuição |
| Zhong Kui | Força de Vontade |
| Agni | Aptidão Mágica |
| Hefesto | Aptidão Mágica |
| Hermes | Carisma · Voz Melodiosa |
| Afrodite | Voz Melodiosa · Carisma |
| Loki | Voz Melodiosa · Noção do Perigo |
| Oxóssi | Senso de Direção · Olfato/Paladar Apurado |
| Ogum | Reflexos em Combate · Hipoalgia |
| Oxum | Empatia |
| Sekhmet | Recuperação Alígera |
| Huitzilopochtli | Recuperação Alígera |

**Duas Casas dividirem Dádiva é o padrão, não a exceção.**

**Reflexos em Combate não é Dádiva de ninguém**: é vantagem comum, comprável por qualquer personagem sem argumento teológico. Atena e Ogum a **concedem**; ninguém a monopoliza.

**Quer uma Dádiva que não está listada?** Escreva **por que ela pertence ao domínio daquele deus**. Argumento teológico bom é aprovado — foi assim que Hefesto ganhou Aptidão Mágica, Afrodite entrou na tabela e Huitzilopochtli ganhou Recuperação Alígera. É assim que o mundo cresce.
